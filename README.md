# Ithra-library-database
Database design project for a library book borrowing system

#ithra Library Book Borrowing System

This project presents the design and implementation of a relational database system 
to manage library book borrowing, reservations, and fines.

## Project Overview
The system manages books, members, borrowing transactions, reservations, and staff. 
It supports tracking book availability, overdue returns, and fine calculations.

## My Role
- Designed the Enhanced Entity Relationship Diagram (EER)
- Mapped entities to a relational schema
- Wrote SQL DDL statements
- Developed analytical SQL queries

## Technologies Used
- SQL
- Relational Database Design
- ER Modeling
